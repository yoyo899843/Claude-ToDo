API Endpoints

Base URL: /api/v1

驗證方式： 每個請求需帶上 Authorization: Bearer <token> header。 Token 可在 個人設定頁 建立。

Todos

GET /api/v1/todos 列出所有 todo，可用 query 篩選 ▸
Request
GET /api/v1/todos?completed=false&q=design HTTP/1.1
Authorization: Bearer <token>
Response 200
{
  "items": [
    {
      "id": 1,
      "title": "更新首頁設計稿",
      "description": "重新排版 hero section",
      "completed": false,
      "created_at": "2026-06-30T19:41:47.703801Z",
      "updated_at": "2026-06-30T19:41:47.703801Z"
    }
  ],
  "total": 1
}
POST /api/v1/todos 建立一筆 todo ▸
Request body
{
  "title": "寫 API 文件",
  "description": "補齊所有 endpoint 的範例"
}
Response 201
{
  "id": 2,
  "title": "寫 API 文件",
  "description": "補齊所有 endpoint 的範例",
  "completed": false,
  "created_at": "2026-06-30T19:43:00.000000Z",
  "updated_at": "2026-06-30T19:43:00.000000Z"
}
GET /api/v1/todos/{id} 取得單筆 todo ▸
Response 200
{
  "id": 1,
  "title": "更新首頁設計稿",
  "description": "重新排版 hero section",
  "completed": false,
  "created_at": "2026-06-30T19:41:47.703801Z",
  "updated_at": "2026-06-30T19:41:47.703801Z"

{ "detail": "Todo not found" }
PATCH /api/v1/todos/{id} 更新標題 / 描述 / 完成狀態（欄位皆為可選） ▸
Request body
{
  "completed": true
}
Response 200
{
  "id": 1,
  "title": "更新首頁設計稿",
  "description": "重新排版 hero section",
  "completed": true,
  "created_at": "2026-06-30T19:41:47.703801Z",
  "updated_at": "2026-06-30T19:50:12.000000Z"
}
POST /api/v1/todos/{id}/toggle 切換完成狀態 ▸
Response 200
{
  "id": 1,
  "title": "更新首頁設計稿",
  "description": "重新排版 hero section",
  "completed": true,
  "created_at": "2026-06-30T19:41:47.703801Z",
  "updated_at": "2026-06-30T19:51:00.000000Z"
}
DELETE /api/v1/todos/{id} 刪除一筆 todo ▸
Response
204 No Content

Events（行程）

GET /api/v1/events 列出行程，可用時間範圍篩選 ▸
Request
GET /api/v1/events?from=2026-07-01T00:00:00Z&to=2026-07-31T23:59:59Z HTTP/1.1
Authorization: Bearer <token>
Response 200
{
  "items": [
    {
      "id": 1,
      "title": "團隊週會",
      "description": "每週進度同步",
      "start_at": "2026-07-07T10:00:00Z",
      "end_at": "2026-07-07T11:00:00Z",
      "created_at": "2026-07-04T08:00:00Z",
      "updated_at": "2026-07-04T08:00:00Z"
    }
  ],
  "total": 1
}
POST /api/v1/events 新增行程 ▸
Request body
{
  "title": "團隊週會",
  "description": "每週進度同步",
  "start_at": "2026-07-07T10:00:00Z",
  "end_at": "2026-07-07T11:00:00Z"
}
Response 201
{
  "id": 1,
  "title": "團隊週會",
  "description": "每週進度同步",
  "start_at": "2026-07-07T10:00:00Z",
  "end_at": "2026-07-07T11:00:00Z",
  "created_at": "2026-07-04T08:00:00Z",
  "updated_at": "2026-07-04T08:00:00Z"
}
PATCH /api/v1/events/{id} 更新行程（欄位皆為可選） ▸
Request body
{
  "title": "更新後的標題",
  "start_at": "2026-07-07T14:00:00Z",
  "end_at": "2026-07-07T15:00:00Z"
}
Response 200
更新後的 event 物件
DELETE /api/v1/events/{id} 刪除行程 ▸
Response
204 No Content
