Gmail 整理流程

          

            

              1
              

                先取清單，不讀內文
                
用 Gmail connector 列出未讀信件（subject、from、date），看 subject 判斷分類，省 token。

              

            

            

              2
              

                按類型處理
                

                  促銷 / 廣告 → 封存
                  需行動（付款、簽署、確認）→ 讀信 + 建 Todo + 連結放 description
                  會議 / 活動 → 建 Todo，deadline 設活動時間，連結放 description
                  一般通知 → 標已讀 + 封存
                

              

            

            

              3
              

                確認後才執行
                
先列出「打算怎麼處理」讓使用者確認，再執行封存或建 Todo，避免誤操作。

              

            

          

        


        

          
建立 Todo 規則

          

            

              
              
deadline 一律使用 UTC ISO 8601 格式，例如 2026-07-10T10:00:00Z

            

            

              
              
重要連結、摘要放在 description，title 保持簡短

            

            

              
              
除非使用者明確要求，否則不刪除 Todo
